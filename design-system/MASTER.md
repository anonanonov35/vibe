# ВАЙБ — визуальная система

Основа: референсы пользователя и поиск ui-ux-pro-max `tattoo studio dark editorial`.
Выбран тёмный editorial portfolio: большие фотографии, нумерованные разделы, тонкие разделители, крупная типографика, минимум рамок и скруглений.

- Фон #10100f; поверхность #191918; основной текст #f3f0e8; вторичный #a6a49d.
- Акцент #ff6b35, текст на акценте #10100f. Светлый блок #e9e6de.
- Заголовки и интерфейс — Oswald с кириллицей, локальные WOFF2 через Fontsource. Основной текст — от 16 px, вспомогательные подписи — от 14 px.
- Ширина контента 1320 px; поля 56 px на desktop, 20 px на mobile.
- Отступы между секциями 112–144 px desktop, 72 px mobile.
- Движение: только короткие переходы и появления; reduced-motion поддерживается.
- Все основные действия доступны с клавиатуры; видимый focus; формы с подписями и ошибками.
- Демонстрационные отзывы и референсы явно обозначаются. В локальной серверной версии фотографии мастеров заменяются через /admin; в версии GitHub Pages используется статический список фотографий.

По правке пользователя удалены круг с отпечатком в первом экране и полоса направлений под ним.

GitHub Pages: демонстрационная форма без отправки данных; загруженная тестовая фотография удалена, показываются четыре эскиза.
